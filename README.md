# shinytoys

Welcome to **shinytoys** — a collaborative playground where students and peers can practice contributing to a shared repository and experiment with fun programming “toys.” This repo serves two main purposes:

* **Hands-on GitHub practice**: Learn and refine workflows like branching, committing, opening pull requests, and participating in code reviews.
* **A collection of neat programming projects**: Share data structures, utilities, algorithms, experiments, and any small, well-scoped creations you find interesting. Contributions in any language are welcome — just keep each toy focused and free of dead or unnecessary code.

## Contributing

Once you’re added as a collaborator, contributing is simple:

1. **Clone the repository** to your machine.
2. **Create a new branch** for your work.
3. Implement your changes, commit them, and **push the branch**.
4. **Open a pull request** targeting the `main` branch and request a review.

Please **avoid pushing directly to `main`** to keep the project clean and collaborative.
